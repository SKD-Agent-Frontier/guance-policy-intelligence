# 管策智研 · 技术方案

## 〇、核心设计原则（最高约束）

> ### 模型不能直接产生政策研究结论。模型只能在可验证证据集合上产生研究结论。


## 一、题面要求的功能清单与应用场景

> 用途：作为范围自查基准。凡不落在本清单内的功能，须明确标为“增强”而非“要求”。

### （一）题面明列的核心功能（7 项）

| # | 功能 | 题面附加要求 |
|---|---|---|
| 1 | 自然语言问答 | — |
| 2 | 片段级引用溯源 | 回答**逐条**标注出处（规划文件名称、章节及片段编号）；**支持点击回看原文**；**严禁编造条文** |
| 3 | 跨区域跨专题对比 | — |
| 4 | 结构化成果导出 | 可导出标准 Word、表格、演示文稿；格式规范、可直接使用 |
| 5 | 政策文献的自动梳理 | — |
| 6 | 政策要素的结构化提取 | — |
| 7 | 多方案比较分析 | — |

外加目标性要求：**智能检索、深度研析与决策辅助**；**为研究者提供数据支撑与逻辑推演辅助**。

### （二）三个使用场景（细则（5）原文）

| 面向 | 要做什么 |
|---|---|
| 师生 | 政策梳理、**报告撰写** |
| 研究 | **多区域、多时期政策演变对比** |
| 决策 | **专题分析、摘要生成**，支撑科学决策 |


### （三）形态与工程约束

- 产物形态：**可部署运行的规划文本智能体 Web 应用**
- 检索：全文与向量检索、**文本索引离线构建**、**支持增量更新**
- 性能：并发**不少于 5**；端到端**不超过 180 秒**
- 算力：公开商用 API 或**经批准的校内算力资源**

### （四）验收指标与隐含要求

- 三项指标：检索命中率 **≥75%**；原文一致率 **≥75%**；引用出处正确率 **≥75%**
- 题库三类：常用问题库、考核题目、**安全性测试题** → **隐含要求：拒答能力与内容安全护栏**
