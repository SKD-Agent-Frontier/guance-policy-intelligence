## 一、榜题 3 细则

### （1）命名释义

“管策”取法先秦名相管仲经国治世、经世致用之学，寓政策研析、治理之略；“智研”寓以大模型智能提升研究效能。二者合而为一，传承“文以载道、明体达用”的人文薪火，使榜题兼具文化辨识度与治理智慧。

### （2）榜题目标

以校内规划文本数据库为基础，建设“管策智研”智能体，通过自然语言问答、片段级引用溯源、跨区域跨专题对比与结构化成果导出，实现海量政策文本的智能检索、深度研析与决策辅助，服务教学科研，推动政策研究数字化、智能化转型。

智能体须具备政策文献的自动梳理、政策要素的结构化提取、多方案比较分析等功能，能够为政策研究者提供数据支撑与逻辑推演辅助，提升政策研究的效率与科学性。

其中，片段级引用溯源要求回答逐条标注原文出处（规划文件名称、章节及片段编号），支持点击回看原文，严禁编造条文。

### （3）智能体的必要性

现有规划文本库收录五万余份公开政策文本、形成一定体量，但检索以关键词为主，用户须逐条浏览、比对、归纳，效率低、门槛高，数据价值远未释放。大语言模型与检索增强生成（RAG）技术日臻成熟，以智能体承接文本挖掘、知识抽取、智能问答与成果导出，可显著提升研究效率与决策支撑能力，破解“文本体量大、利用不足”的现实矛盾。

### （4）可行性（含数据条件）

数据方面：发榜单位可提供校内规划文本库只读访问，共五万余份各级政府公开发布文件，均为正式公开发布，合规、无涉密风险，可用于开发测试。实测全库共收录规划文件 53,161 篇（规划文件 40,744 篇、政府工作报告 12,417 篇），正文总字数约 12.17 亿字，数据库正文文本覆盖率达 98.9%。文本源自政府网站公开发布的电子原生文件，非扫描件，不需大规模 OCR 处理。

技术方面：RAG 范式成熟，全文与向量检索开源方案齐备，文本索引离线构建、支持增量更新。

算力方面：可采用公开商用 API 或经批准的校内算力资源。

资源方面：集中式线上部署，支持校内并发 10 人、单次问答 120 秒内，三个月内工作量可控，成果可复现、可推广。

### （5）预期成效

产生一个可部署运行的规划文本智能体 Web 应用，满足以下需求：面向师生，政策梳理、报告撰写；面向研究，多区域、多时期政策演变对比；面向决策，专题分析、摘要生成，支撑科学决策。

主要验收指标：检索命中率不低于 75%；回答内容与规划文本原文一致率不低于 75%；引用出处正确率不低于 75%；支持不少于 5 个校内用户并发访问，单次问答端到端响应时间不超过 180 秒；问答结论与对比分析可导出为标准 Word、表格、演示文稿等文件，格式规范、可直接使用。

评测采用验证集与测试集分离方式：验证集由发榜单位统一提供，供参赛队自测调优；测试集不公开，由发榜单位在评审阶段统一离线评测。题库分常用问题库、考核题目、安全性测试题三类，所有题目均须提供“题目＋参考答案＋验证标准”。

须同时交付应用源码、部署文档、运维手册、测试报告、演示视频及答辩材料等项目文档。

## 三、关键数字与验收指标速查

- **语料规模**：53,161 篇（规划文件 40,744 篇 + 政府工作报告 12,417 篇）；正文总字数约 12.17 亿字；正文文本覆盖率 98.9%
- **语料性质**：各级政府正式公开发布；电子原生文本，非扫描件；合规、无涉密风险
- **访问方式**：发榜单位提供校内规划文本库只读访问
- **验收指标**：检索命中率 >= 75%；回答内容与规划文本原文一致率 >= 75%；引用出处正确率 >= 75%；并发 >= 5；端到端 <= 180 秒
- **部署形态**：集中式线上部署
- **评测方式**：验证集（发榜单位提供，题目 + 参考答案 + 验证标准）供自测调优；测试集不公开、由发榜单位离线评测；题库分常用问题库、考核题目、安全性测试题三类
- **交付物**：应用源码、部署文档、运维手册、测试报告、演示视频、答辩材料；成果可导出为标准 Word、表格、演示文稿

评分结构（决定资源分配）

综合得分 = 初赛 × 20% + 师生体验 × 10% + 决赛 × 70%。

- 初赛 100 分中“智能体技术创新”占 25 分，其要点首项即**RAG 知识库构建质量**；“团队协作与分工”5 分含**培训参与情况及证书获取情况**。
- 决赛 100 分中“现场路演与演示”25 分、“答辩表现”20 分，合计 45 分，为占比最高项。
