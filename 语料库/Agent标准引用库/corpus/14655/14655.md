2000年工作和“九五”简要回顾　　2000年，是世纪之交的一年，也是我区改革开放不断深入发展，经济建设和社会事业继续前进的一年。在市委、市政府和区委的领导下，在区人大、区政协的监督支持下，区政府团结和带领全区人民，以邓小平理论和“三个代表”的重要思想为指导，认真贯彻党中央一系列重大决策，紧紧围绕经济建设这个中心，锐意改革，开拓进取，积极推进两个文明建设协调发展，较好地完成了区十二届人大四次会议确定的各项工作任务。 　 　一、城乡经济持续健康快速发展 　　认真贯彻区委七届三次全会精神，以实现“五个新的突破”为目标，进一步解放思想，更新观念，千方百计，强力推进，经济建设取得丰硕成果。招商引资实现新的突破。坚持把招商引资作为“五个突破”的龙头和中心环节，进一步加强招商引资基础工作，不断完善目标考核体系，及时兑现有关经济政策，全区上下形成了浓厚的招商引资氛围，招商引资额度和质量有了明显提高。全年招商引资总协议资金额 39，310 万元，实际到位资金额38，500万元；新办招商引资企业177 户， 其中，注册资金超千万元的企业6 户，形成了平达公司、鑫捷奥实业有限公司、太平洋商厦等一批具有一定规模和带动作用的骨干企业。区域联合实现新的突破。按照“借大厂力，打汽车牌，走配套路，求大发展”的工作思路，利用区属企业机制灵活和驻区大厂在项目、技术、人才、市场方面的优势，区厂联手，广泛开展“内内外”形式的招商引资活动，推动区域联合向深层次发展，扩大了税源企业的群体和实力。全年共新办区域联合企业48 户，新增产值16，200 万元。非公有制经济实现新的突破。坚持“放胆、放手、放量”的发展原则，进一步优化政策环境和经营环境，加强引导和规范，充分发挥有关职能部门的作用，调动街道办事处和镇政府的积极性，千方百计为非公有制经济发展提供便利条件，为下岗职工、特困职工和各类社会力量发展个体私营经济排忧解难，促进个体私营企业不断扩大经营规模，非公有制经济继续保持强劲发展势头。个体私营经济实现营销额 53，010万元，产值27，010 万元；个体工商户和私营企业分别新增850 户和63 户。产权制度改革实现新的突破。继续以股份制、股份合作制改造为重点，通过“卖给民营”、“交给职工”、“送给大厂”等多种形式，结合招商引资，积极推进企业产权制度改革，实现投资主体多元化。一方面继续解决好部分改制企业的遗留问题，推进企业机制创新和管理创新，巩固改革成果；另一方面进一步解放思想，更新观念，打破地区、行业和所有制界限，从实际出发， 因企施策， 加快存量资产的优化重组，产权制度改革取得了突破性进展，完成了年初确定的工作目标。质量效益型农业实现新的突破。以市场为导向，以基地建设为重点，不断调整和优化农业结构，大力发展农副产品精深加工龙头企业，推进了农业产业化进程。种植业发挥传统优势， 实施秋白菜名牌战略， 发展棚室生产， 重点引进推广优良品种和新技术，增加甜玉米、韩国秀光蕃茄、日本早熟黄瓜等播种面积；养殖业在巩固蛋鸡、生猪、奶牛传统饲养的同时，发展特色养殖， 重点开发蓝狐、梅花鹿、三黄鸡、乌骨鸡等新、奇、特品种。进一步发展农村各类中介组织，积极为农民提供产前、产中、产后配套服务，提高了种养业比较效益。粮食产量达到1，330 万公斤，蔬菜产量达到7，320 万公斤，提供商品肉260 万公斤、鲜蛋700 万公斤、鲜奶760 万公斤。加强了农业基础建设的多元化投入，新建大棚30栋，温室30栋；新修田间道路30公里；新打机电井21眼；新增小型农机具64台（套）。投资380万元，筹建了占地3万平方米的新华蔬菜批发市场。经济发展环境明显改善。深入开展“为经济建设服务，树行业新风”和“双先”、“双差”评比活动，增强了改善经济发展环境的针对性和实效性。进一步完善“七卡”运行体系，强化跟踪问效，增强了政府职能部门的效率意识和服务意识。集中开展清费治乱、减轻企业和农民负担等专项治理活动，重点对影响经济发展的倾向性问题和不良现象进行了整治，加强对重点企业挂牌保护的动态管理，有力地促进了地区经济发展。 　　2000年，我区经济继续保持健康快速发展势头 ，经济总量进一步扩大，经济效益明显提高。区属经济国内生产总值实现53，000 万元，比上年增长10.4 %；总产值222，820 万元，比上年增长23.6 %；销售收入236，150 万元，比上年增长22.4%；利润总额4，990 万元，比上年增长15.1 %。其中，农业总收入15，780 万元，比上年增长6.1 %。乡镇企业实现总产值173，020万元，比上年增长27.1 %；利润总额3，910万元，比上年增长14.8 %。农民人均收入达到3，302元，比上年纯增112元。商饮服业实现营销额45，770万元，比上年下降2.9 %；利润总额900万元，比上年下降14.7 %。建筑业实现产值31，680 万元； 利税800万元。房地产开发施工面积 22，450平方米，竣工面积22，450 平方米，实现销售收入 1，920万元；利税350万元。财政收入5，538万元，比上年增长15.7%。 　　二、城区环境质量明显改善 　　一年来，我们紧紧抓住全市实施城市形象工程的有利契机，动员社会力量，区厂联合，深入开展城市环境综合整治，努力加快城市基本建设，改善城区环境质量。投资400万元，改造了联盟大街南段及11条三、四类街路，维修道路12，840平方米，新铺步道板8，150平方米。以“一控双达标”为核心，认真做好环境保护各项工作，我区水、气、声、渣等方面的环保指标均达到市政府考核标准，并继续保持在全市的领先水平。实施拆棚还绿工程，共拆除棚厦4，400余个，占地面积40，000平方米；投资300余万元，完成了友协西头道街1，110平方米绿地、新疆大街北段沿街3，350平方米绿地、友协街4，000平方米游园和东升街25，780平方米休闲广场等项重点工程；新铺草坪27，860平方米，植树5，000余株，绿化覆盖率达到32.05%，人均公共绿地面积达到8.49平方米。筹资100余万元，进行了垃圾处理场基础设施建设。深入实施畅通工程，清理机动车违章占道5，600余台次，严厉打击野蛮拉客和非法营运行为，交通秩序和运营秩序得到明显改善。整顿基建工地9处，清理私建滥建350余处，拆除商亭、电话亭300余处。进一步加强市场摊区整顿，清理违章占道、街头烧烤、沿街刷车点2，000余处，取缔无证商贩15，000余人次。加强庭院建设，辟建了9个绿化景观庭院和25个绿化达标庭院，居民小区环境得到明显改善。 　　三、精神文明建设水平进一步提高 　　在搞好物质文明建设的同时，不断加强精神文明建设，我区继续保持“省级文明城市建设先进区标兵”荣誉称号。以爱国主义、集体主义和社会主义教育为核心，深入开展多种形式的群众性精神文明创建活动，市民文明素质和城区文明程度有了明显提高。实施科教兴区战略，科教兴区目标责任制得到进一步落实。科技兴工、科技兴农取得新成绩，全年实施星火计划5项，开发新产品10项，引进各类项目20余项，其中，涡街流量计项目技术性能达到国际先进水平；推广农业适用新技术16 项，引进种养业新品种20 项；新办民营科技企业8 户。教育事业不断发展。深化教育体制改革，积极推进素质教育，不断加强师资队伍建设，加大“减负”工作力度，农村教育达到全省一流水平，中小学教学质量稳步提高，顺利通过了省、市“两基”工作复检。全区初中升学率为89 %， 高考升学率为82.3 %。完成了100中学5，800 平方米教学楼建设和保国二校、四校校舍改造工程，启动实施了84中学教学楼和24中学综合楼建设工程。文化体育事业进一步繁荣。广泛开展多种专题文艺活动和社区文化活动，丰富了全区人民的业余文化生活。加强文化市场管理，对音像市场、电子游戏及歌舞娱乐场所进行集中清理整顿，严厉打击了“黄、赌、毒”等社会丑恶现象。投资20万元，建立“全民健身路径”，促进了群众性体育活动广泛开展。深入开展“婚育新风进万家”活动，加强初级生殖保健工作，进一步落实计划生育目标管理责任制，不断提高计划生育服务水平。计划生育率为99.6 %，人口出生率为5.83‰。医疗卫生事业不断发展。开展了以病人为中心的优质服务活动，医疗护理质量有所提高。依法加强医政药政管理，取缔非法行医和游医药贩，净化了医药市场。筹资60余万元，改善了妇幼保健所医疗服务条件。卫生防疫、计划免疫、食品卫生等工作都取得了较好成绩。群众性爱国卫生运动广泛开展，创建卫生城工作成效显着，顺利通过国家复检，继续保持“省级卫生文明区”荣誉称号。 　　四、“731”遗址保护开发工作取得明显成效 　　一年来，我们把“731”遗址保护开发作为重点工作之一，认真做好前期调研和开发论证工作，积极争取省、市重视和有关部门的支持，以争取列入“国家级文物保护单位”和“世界文化遗产”为目标，以地面非保护建筑拆迁、地下遗址发掘、单体文物保护等项工作为重点，精心组织，全力推进，取得了阶段性成果。共拆除保护区内民房122户、公企单位11个、东轻公司厂内5处遗址周围非保护建筑设施 3，900平方米，平整场地53，000平方米。启动了25中学的搬迁工作，收回部分本部大楼遗址，并进行了重新修缮。借鉴外地布展先进经验，初步形成了遗址布展工作实施方案。完成了冻伤实验室、黄鼠饲养室等6处遗址的周边环境清理、文物围护、甬道铺设和文字说明等项工作。对部分地下遗址实施了抢救性挖掘，共发掘细菌弹片、高压锅炉残片等文物20余件。深入开展罪证挖掘和文物收集工作，成功地进行了跨国取证，共征集文物及有关资料100余件。以“建设爱国主义教育基地”为主题，广泛开展了遗址建设募捐活动，全市共接到社会各方面捐款743万元，其中我区捐款134万元。 　　五、社会稳定进一步巩固 　　一年来，我们自觉地把政府工作置于区人大依法监督和区政协的民主监督之下，积极主动地向人大及其常委会报告工作，与政协进行民主协商，增强了决策的民主性。全年共办复人大代表意见、建议75 件，政协委员提案 106件。不断加强基层政权建设，深入开展村民自治，圆满完成了第五届村民委员会换届选举，农村村务、财务公开率达到100% 。较好地完成了“三五”普法验收工作，公民的法律意识明显增强。全面落实社会治安综合治理各项措施，深入开展“打击人贩子，解救被拐卖妇女儿童”和“夏季破案会战”等专项斗争， 破获各类刑事案件441 件，其中重特大案件242 件，刑事案件破案率为59.1 %，重特大案件破案率为64.5 % ，有效遏制了刑事案件特别是重特大案件发案率上升势头。深入开展“安全文明”创建活动，39个小区、15个村、71个单位达到创建标准。落实安全工作责任制，加大安全教育、监督和隐患整改力度，生产、防火、交通等方面各项安全指标均控制在市下达指标之内。深入开展拥军优属、拥政爱民活动，被民政部授予“爱心献功臣”先进区称号。积极推进再就业工程，安置下岗职工再就业1，204人。社会保障工作得到加强，全面落实城乡居民最低生活保障制度，共发放抚恤、救济金170万元，养老保险金发放面达到离退休总人数的90 %以上，失业保险参保率达到95 % 以上。残疾人事业和老龄事业进一步发展。认真做好人民群众来信来访和人民建议征集工作，共受理信访4，300 人次，征集人民建议43 件。 　 　六、政府自身建设得到加强 　　以培养高素质的公务员队伍和建设团结、务实、廉洁、高效的政府机关为目标，不断加强政府自身建设。按照中央和省、市、区委的统一部署，深入开展以“讲学习、讲政治、讲正气”为主要内容的党性党风教育，认真查找和深刻剖析领导班子和领导干部在党性党风方面存在的突出问题，制定并落实了整改措施，“三讲”教育取得明显成效。认真组织政府工作人员有计划地学习邓小平理论、“三个代表”的重要思想、党的十五届五中全会精神和有关法律法规及现代科技知识，不断加大公务员的培训力度，提高了公务员的政治素质、业务素质和专业技能。强化政府工作目标责任制，进一步完善统一协调的运行机制，对重点工作实施专项推进，促进了工作落实。以警示教育为重点，广泛开展廉政勤政教育；深入开展纠风专项治理和综合整治，认真查处违法违纪案件；加强行政执法监督检查，规范行政执法行为，加强了党风廉政建设。 　　充分发挥驻区大企业和市直单位的作用，依靠全区人民，顺利进行了第五次人口普查。此外，我区的审计、物价、统计、征兵、档案、民族宗教和地方志等项工作都取得了较好成绩。 　　各位代表，“九五”期间，全区人民在党的十五大精神指引下，紧紧围绕经济建设这个中心，坚持两个文明一起抓，解放思想，深化改革，克服困难，锐意进取，国民经济和社会发展取得长足进步，“九五”计划各项指标提前一年超额完成，精神文明建设得到加强，为实施“十五”计划奠定了良好的基础。主要表现在： 　　国民经济持续发展，经济实力明显增强。与“八五”末相比，区属经济国内生产总值增长了56 % ，年均递增9.3 %；总产值增长了322 % ，年均递增33.3 %；财政收入增长了72.4 %，年均递增11.5 %。农业基础地位得到加强，农村经济全面发展。农业由数量型向质量效益型转变的步伐加快，乡镇企业产值占全区总产值的比重达到79%，成为区属经济发展的主力军。工业经济快速发展，以汽车及零部件配套生产为主导，带动区属经济发展的模式已初步形成。第三产业发展的质量和水平明显提高。在所有制结构调整方面取得突破性进展，非公有制经济呈现强劲发展势头。 　　社会事业不断进步，人民生活水平显着提高。城市基础设施建设步伐加快，载体功能进一步增强。完成了保国大街、联盟大街、友协大街等主要街路的改造工程；危棚房改造取得前所未有的成效，新建住宅楼达40余万平方米；建设了一批高档次、高质量的休闲广场和绿化景点，城区整体面貌明显改善。科技进步对经济增长的作用明显增强。教育、文化、卫生、体育等各项事业进一步繁荣，住房、社会保障制度等方面改革取得了良好成效。城乡人民生活基本达到小康水平。
