# 政策文献主题分类 v1

## 数据来源与约束

- 源表：`原始数据库/管策智研_示例数据集/metadata/sample_plans.csv`，共 506 个唯一 `planid`。
- 输出：`policyTopics.json`，独立于政策原文、RAG 索引和原始元数据。
- 分类基于样本文献标题以及已有的元数据记录，未逐篇阅读全部正文；分类内容**不等于**全文语义理解结果。
- 一篇政策允许有多个主题；没有充分标题证据时保留空标签。
- 只有当前样本文献数达到 **3 篇** 的主题才保留为系统公开分类。
- 主题并非用户自定义研究专题。系统主题按版本发布；个人专题由用户保存所选 `planid`，当前前端 MVP 保存在浏览器 localStorage。

## 质量边界与后续升级

系统分类采用标题可判定的政策主题，不把政府工作报告的所有相关内容自动推断为其下属领域；因此综合性文件通常只进入“综合发展与政府工作”。

分类误差来源：标题与实际正文主题不一致、标题覆盖多个政策议题、版本修正、未提及于标题的正文重点。对于命名语义不明确或需要全文确认的边缘案例，应升级到章节标题与正文证据的二阶段分类，再更新本文件的 `method` 与版本号，不能宣称这一版已有逐篇语义核验。

前端专题管理不改变后端 `kb_search` 约束，不能把个人专题误认为 Agent 已经获得专题内的检索 scope。
