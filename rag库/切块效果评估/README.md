# 两版切块效果评估产物

当前为历史评估档案：开源组件版已于2026-10-23按用户要求删除，原始对照结论、逐题指标和本目录证据保留。evaluate.py会在被移除工程不存在时明确停止，不新建目录、模型任务或数据库。Git只保存代码及摘要，不能恢复已删除且从未纳入Git的批次数据。

本目录为2026-10-23的独立评估产物，不属于正式RAG输入。评估只读原始切块及现有向量库，未修改文档向量、Qdrant集合或发布指针。代码、摘要和报告纳入Git；问题向量与检索明细保留本地并排除，避免重复存储大体积生成数据。

| 文件 | 作用 |
|---|---|
| .gitignore | 排除问题向量、原始返回、查询缓存和临时文件；保留代码与评估摘要 |
| 对照报告.md | 结论、方法、完整性复核、检索结果和局限 |
| evaluate.py | 同源结构比较、问题向量断点缓存、两版精确检索和指标计算；含中文规则说明 |
| structural_comparison.json | 506篇来源核对、区间/输入一致性及原生状态统计 |
| questions.json | 785道题干及仅用于评分的参考planid；不是送入模型的完整对象 |
| query_profile.json | 题干哈希、模型、tokenizer、通用指令和实际token数 |
| query_vectors.npy | 785×4096 float32问题向量；两版共用，可避免重算问题 |
| embedding_calls.jsonl | 本次问题嵌入调用、usage和耗时；没有凭证 |
| legacy_retrieval.json / oss_retrieval.json | 每题现有集合的真实精确检索Top20，保留point/块/父块/来源编号和分数 |
| evaluation.json | 文档级命中、覆盖率、MRR、分类/单题子集、逐题结果及配对bootstrap区间 |
| difference_cases.json | 8道Hit@1或Hit@10变化题及首个参考政策的原文片段 |

重新复现两版比较需先从Git历史恢复开源版代码并重建其数据，再使用项目既有向量环境Python执行evaluate.py；目前不直接运行该双版评测。凭证只从保留工程本地私密配置读取，不能复制进本目录。更换正式集合、题库或输入配置时应建立新的独立评估目录，不能混用历史返回结果。

评价范围为训练集开发题上的文档级纯向量检索。K指返回的文本向量记录数量；通常对应子块，超长子块可能对应多个分片。它不是片段级精确率、最终问答质量或独立测试集成绩。文件变化时同步更新本表及对照报告。
