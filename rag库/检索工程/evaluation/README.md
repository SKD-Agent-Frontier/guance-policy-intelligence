# 初始检索基准

本目录包含一个 21-query、每题单一相关 chunk 或媒体来源判断的初始检索基准。每条 qrel 附来源 planid、标题和对应原文证据，相关 ID 来自恢复 runtime 的 metadata；该标注集用于初步比较，不代表穷尽所有相关文档或完整相关性判断。

以发布的 runtime 运行 `bm25-results.json`：Recall@5=0.9047619048、Recall@8=0.9523809524、Recall@20=1.0、MRR=0.7681216931。包含“逝有所安重点工程 骨灰安放 殡仪馆”探针；其目标来源排名第18，Recall@5/8 均为 0。

Hybrid 未完成：恢复交付没有私有 embedding 服务配置，运行尝试在首次查询阶段无法取得向量结果；因此不生成或推测 Hybrid 指标。
