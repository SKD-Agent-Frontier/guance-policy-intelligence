# 方案归档

这里只保留当前运行链路仍然需要的历史文件；原 PostgreSQL/Qdrant Server 源码、1.0 设计方案
与早期切块评估已从仓库移除。

## legacy_migration/

`config.json` 与 `当前批次.json` 是原 `向量化与存储工程` 的原字节副本。

本地存储工程的 `migration_source` 选项需要读取这两个文件来定位旧冻结数据；本机旧库路径
`rag库/向量化与存储工程/` 由 Git 忽略，从未进入仓库。保留字节副本是为了让已存在的本地
迁移配置继续可用，不代表本目录可以独立运行历史服务。

索引、向量、数据库、环境与凭证从未提交，也不在本目录内。
