# 开源组件版维护约定

- 用户已查看改进说明并授权首次实施；后续操作范围以当次用户请求为准，不沿用说明编写阶段的“等待开始”状态。
- 父子候选必须实际调用 LlamaIndex 官方组件；不得复制旧版 `make_parents`、`make_chunks`，也不得把项目约束调整冒充官方原始边界。
- 代码、配置、依赖、文档或目录变化时，同轮同步更新 README 的结构、职责、入口、状态及实际验证；正式批次变化同时更新批次 README 和当前批次指针。
- 关键代码用中文解释输入输出、Unicode 坐标、原文映射、引导语/附注、表格保护、异常处理与 token 防截断。
- 原工程和输入语料只读；生成数据独立保存，既有无关变更保留。未知、歧义及不能安全切分的范围如实待处理。
- 依照用户的仓库工作约定，相关检查后仅本地提交本任务变更；不推送或部署。
