# 切块工程维护约定

适用于本目录及其子目录。用户要求：后续文件有更改时同步更新 README。

- 新增、删除、移动、重命名或修改本工程文件时，在同一轮修改中核对并更新本目录 `README.md`，不能只在最终回复中承诺以后再补。
- 目录变化同步更新目录树、文件作用和链接；代码、配置或依赖变化同步更新相关职责、入口、参数、运行方式、输出格式和边界。
- 仅注释或文案变化也在 README 的维护记录简述；说明实际发生的变化，不虚构功能或验证结果。
- 正式批次变更时，同时更新 `当前批次.json` 和 README 的数据入口；旧批次的验收记录保留其原始版本含义，不改成新代码的验证证明。
- 对照实际目录验证 README 中的文件和链接。缓存及临时文件按用途归类，不要求列举每个自动生成文件。
- 纯文档修改采用直接检查即可；不为更新 README 重新切块或改写原始语料。
