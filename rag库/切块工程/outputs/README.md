## 为什么保留多个批次

实施过程中，规则修正后会重新运行样例或全量处理，并保存新的批次，供比较输出及追溯原文快照。`all-` 表示全量，`sample-` 表示固定样例；名称中的两段字符是配置/代码和输入清单相关的指纹，不是日期或递增版本号。

最近补充代码注释、工程 README 和本索引时，没有重新切块；这些文档修改没有产生新的数据批次。
