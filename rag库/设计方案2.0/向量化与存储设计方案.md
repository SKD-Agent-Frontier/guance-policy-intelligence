## 1. 沿用的技术路线

> 父子块及图片处理 → 来源校验 → 重复识别与输入分组 → 向量生成或复用 → 关联存储 → 对账后发布。

沿用 Qwen/Qwen3-VL-Embedding-8B、4,096 维、Cosine、Qdrant＋PostgreSQL，以及文本、图像和必要图文组合的表示思路。实施时固定模型版本、processor、模板、归一化和实际输入上限；以上是设计配置，不是已完成的运行验证。

| 保存位置 | 内容 |
|---|---|
| 来源快照及派生文件 | 原始 Markdown、原图、裁剪图、识别结果及各自哈希；原件不覆盖 |
| PostgreSQL | 文档版本、父子块、必要关联、媒体及区域、输入与向量映射、任务状态和发布清单 |
| Qdrant | 每个来源表示一条向量，带来源、父子块或图片身份及过滤字段 |
| 批次文件目录 | 向量缓存、配置、成员清单、失败项和校验报告；关联同批 BM25 索引 |

原设计以程序校验筛选可用对象，不要求 1.0 的全量模型复核或人工裁决记录。后续完整覆盖实现仍必须通过来源位置/归属等确定性校验，但已有 pending/依赖/质量问题以标签保留，不自动排除原子块；入库资格不等于可以独立支持政策结论。

## 2. 图片与识别内容

保留“原图 → 内容识别 → 按语义切分 → 映射原图 → 向量化”的流程：

1. 登记文件哈希、尺寸、可读状态、文档归属与出现位置。图片缺失或归属不明时保留异常，不猜页码。
2. OCR/视觉识别模块提取文字、阅读顺序和区域，结果单独保存。Embedding 只生成向量，不代替文字识别。
3. 正文按段落形成派生父子块；表格保留整表与可靠行组，图表保留图题、图例和单位，公式关联符号定义。跨页关系不清楚则标记上下文不足。
4. 原图或语义区域可生成图像向量，识别文字可生成文本向量，需要图题上下文时使用图文表示；按实际需要选择，不机械生成所有组合。
5. 程序检查资源存在、区域坐标合法、派生文字位置及父子归属有效、实际视觉输入不超限。识别失败或已检测到关键字段异常的内容保留状态，不作为确定事实输出。

取消对图片分类、结构和切分结果的全量大模型复核及人工裁决。程序检查不等于识别正确：OCR 始终标为“识别文本”，保存引擎版本并提供原图入口，不冒充 Markdown 原句；答案中的金额、年份等不能仅凭识别置信度判定准确，无法确认时展示原图并说明不确定。

图像记录 `asset_id`、`occurrence_id`、原图 bbox 和尺寸；识别块另记 `visual_chunk_id`、识别版本及派生文字范围，不伪造 Markdown 字符位置。

## 3. 去重与向量复用

沿用向量化前去重：原文指纹记录完全相同内容；字符 n-gram 与 MinHash/LSH 提出近重复候选，保存差异和各自来源。程序比较数字、单位、地区、时期、否定和条件等字段；无法确定的关系保持候选，不安排强制人工裁决。

- 仅在实际输入与模型配置完全相同时复用向量计算；同正文但标题、地区或上下文不同，按各自输入计算。
- 近重复只记录关系，不自动删除来源、合并事实或共用不同输入的向量。
- 各文档保留自己的 planid、父子块和引用位置；缓存共享不等于来源合并。
- 图像缓存同时考虑区域、预处理和附加文本；同图不同上下文不能误用图文缓存。

`representation_id` 区分文本、图片和图文表示，确定性映射为 UUID point ID；同一来源的不同表示不能互相覆盖。父块主要用于原文回取，默认索引文本子块及选定的媒体表示。

## 4. 构建、增量与发布

1. 固定来源快照、切块版本、模型配置和本批 `generation_id`，登记合格与排除对象。
2. 复用未变化对象及相同输入的缓存，只处理新增或变化内容；逐项记录模型调用、失败和重试。
3. 在新 collection 写入完整发布成员，使用固定 point ID 重试；向量检查维度、有限值、非零及归一化。
4. 核对 PostgreSQL 表示清单与 Qdrant point 的 ID 集合、来源和输入映射；BM25 只对应可检索文本成员，纯图像不要求有词法记录。
5. 校验通过后在 PostgreSQL 中更新当前批次指针。每次查询固定同一批次的来源、配置与索引，失败批次不启用。

增量指差量解析和计算复用，发布仍使用完整新 collection。来源内容或识别结果变化时生成新版本，不覆盖旧引用。任务状态持久化，同批次可恢复和重试；首轮单 worker 即可，不引入复杂调度。

单项失败可重试；需要先发布部分数据时，在发布清单及相关索引中一致排除失败对象并标明缺口。备份保存同批来源、配置、关系数据和索引；恢复或回退后重新核对成员与引用。

## 5. 必要验证

验证输入无静默截断、向量与表示对应、同输入缓存可复用、不同来源身份不合并、图片可定位、重试不增重复对象、失败批不生效，以及更新后旧引用仍可读取。

报告区分原文件数、父子块数、媒体数、独立来源数、唯一模型输入数和向量数，避免把缓存节约误报为来源减少。验证采用程序对账和固定样例，不恢复全量模型审核或人工审批流程。
