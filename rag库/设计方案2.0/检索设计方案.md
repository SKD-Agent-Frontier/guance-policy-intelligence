# 检索设计方案 2.0

日期：2026-10-21。本文为设计，未运行检索评测。上游：[向量化与存储设计方案](向量化与存储设计方案.md)；返回[方案概要](RAG库技术方案概要.md)。

## 1. 简化后的检索链

> 问题与明确筛选 → BM25＋向量召回 → RRF 融合 → 父块及必要关联回取 → 回答与引用校验。

保留 BM25S＋jieba、既定 Qwen 模型＋Qdrant，以及 LangChain 父块回取适配思路。两路使用同一批来源与过滤条件，不重新切分上游父子块。文本子块和可用识别文字走词法与向量两路，纯图像只走向量路。

去掉独立重排模型、自动研究任务拆解、循环补取、近重复候选池和复杂跨来源折叠。原有离线重复关系保留，在线只合并同一来源单元的多路命中，同一父块回取一次；不同文件继续保留各自出处。

首轮每路取前 20 个候选，以 `Σ 1/(60＋名次)` 融合；同一来源单元的多种表示在同一路只取最好名次，避免重复加分。优先选前 5 个候选并回取上下文，参数仅为调试起点。候选无效或预算不足时减少返回量并说明原因，不循环扩搜。

## 2. 筛选与完整证据

- 使用明确的 planid、地区、时期或文件类型条件；元数据未知不视为满足硬条件，不混淆发布日期、报告年份与目标年份。
- 两路都在符合条件的集合内选 Top-K；结果再核对来源和条件，不能先截全库结果再过滤。
- 已知片段或原文范围时直接读取；一般查询先用子块定位，再回取同版本父块及规则明确解析的必要关联。
- 共同条件、否定、例外、表头和单位随证据一起提供；依赖未解决的候选标记上下文不足，不单凭金额句生成结论。
- 按回答模型实际预算装配证据。父块过长时，只选能保留完整条件的既有单元及其关联；仍装不下则说明不足，不截半个条文或表格。
- 明确比较多个对象时分别检索、分别列出处；一方缺证据就写明缺口，不自动扩展比较维度。

图片证据同时回取原图及区域，识别文字标明派生性质。若回答模型不能读取图片，只展示图片入口及不确定说明，不仅凭向量命中推断图中事实。

## 3. 引用生成与校验

程序生成 `evidence_id`，绑定批次、文档版本、父子块或图片身份，以及实际引用范围。模型接收证据和编号，生成“结论＋证据编号”；标题、位置、引句和原文入口由程序生成，不由模型补造。

| 项目 | 本版要求 |
|---|---|
| 身份 | 引用必须属于本次提供的证据，不接受模型编造的编号 |
| 文本原句 | 按快照哈希和码点范围取回并逐字校验；检索前缀和模型解释不是原句 |
| 图片及 OCR | 原图存在、区域和识别版本可定位；展示原图及识别标识，不把 OCR 当作原生文本 |
| 上下文 | 结论与对象、地区、时期、条件、数值单位和例外一致；证据不足时收窄结论或明确说明 |
| 展示 | 引用可打开冻结版本并定位；没有真实页码、章节或官方链接时不编造 |

文本位置正确不等于结论受到支持。回答模型根据已提供的父块和必要关联组织有依据的回答，不增加独立的逐条大模型复核调用或人工审核步骤；程序负责可确定的身份、位置、文本和关联校验，不能把这类检查报告为语义正确性保证。

不同事实分别引用，条件和金额来自两处时两处都标注。政策原句与分析分开呈现；本地来源可追溯不自动等于官方认证或现行有效。

## 4. 输出与验证

输出回答、引用、来源信息、原文或原图入口、实际筛选条件及证据不足说明。未命中表示本次范围内未找到，不表示政策不存在；索引故障单独报告检索失败。

用固定样例验证明确条款、否定与数字、同句多处出现、父块共同条件、跨条依赖、表格和图片、不同地区同文、旧版本引用及无证据问题。自动检查：

1. 引用身份、来源、文本范围或图片区域有效，失效引用不进入最终输出。
2. 子块回取正确父块，已解析的必要关联没有遗漏，最终证据不被预算处理截坏。
3. 已有预期原文范围的样例命中相应证据；仅有文档编号的题库只用于文档级召回检查。

报告程序校验结果、固定样例结果和未解决问题，不强制全量模型或人工复核，也不把定位通过率称为回答准确率。本次仅交付设计，建库及效果数据待实施后据实记录。
