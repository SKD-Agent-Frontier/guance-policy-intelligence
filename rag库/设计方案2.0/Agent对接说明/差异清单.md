# 当前契约、实际 RAG 与修订设计的差异

日期：2026-10-23。对照对象为 [Agent 契约 V0.1](../../../agent/contracts/kb_contract.md)、实际 Agent 类型/工具和降级版 RAG；本轮只修改设计及本交付目录，**以下生产差异尚未消除**。

## 一、接口契约差异

| 项目 | 当前 Agent / kb_contract.md | 当前真实 RAG | 拟议改动与位置 |
|---|---|---|---|
| 后端入口 | 同步 KnowledgeBase.search/read，实际只有 MockKB | 同步 query 返回嵌套 dict；有三个存储 Protocol，没有同形 KnowledgeBase | RAG 新增同步适配器；Agent kb.py 增加分支，config.py 同时放开真实后端枚举 |
| 加载与共享 | MockKB 缓存，但首次使用才建立 | query 每次开关库、加载成员及 BM25；CLI 持锁拒绝并行进程 | RAG 启动预加载一个冻结发布，单个库工作线程持有连接和索引，多请求排队共享；不能直接跨线程复用 SQLite connection |
| 地区筛选 | area 包含匹配元数据地区名 | area_name 目前为等值过滤 | 适配器按真实元数据建立包含匹配集合，在两路 Top-K 前应用；不猜行政区划、不在召回后才过滤 |
| 规划期 | fyp 已做十一五至十五五等别名归一化 | period_key 对应 fyp_name，等值；可能为空或“政府工作报告” | 字段映射并保留原值，空值转 null；不把报告年份猜成某个五年规划期 |
| 完整块与摘要 | Hit 只有实际 content 的 char_start/end；300 字会截断 | source_segments 保存完整块；retrieval_text 另含增强前缀 | Hit 新增 chunk_char_start/end、truncated，保留实际返回范围；原文 content 不取增强输入 |
| 坐标原点 | 写完整 body，但 Mock body 没有实际语料 front-matter | 完整冻结 MD，包含 front-matter 和 CRLF | 契约明确 offset_basis、offset_unit、body_start；不得只改名字就套用到去除元数据的 body |
| 文档版本 | 大部分证据只保留 planid | document_id/source_hash/generation_id/document_version_id 均已存在 | 新类型及 EvidenceRef 保存各自真实身份，历史读取不能仅按 planid 选最新版 |
| chunk_id | 允许真源 ID，但未说明生成或稳定性 | chunk_摘要；配置含 tokenizer 和代码字节指纹 | 沿用原 ID；保留旧对象/快照；只承诺同冻结产物重建稳定，不能承诺重新切块永远相同 |
| representation_id | 旧类型无此概念 | 一个 chunk 可对应多个向量输入表示 | 检索表示映射回 source.id，引用不绑定表示或 point；身份字段分开保存 |
| 章节身份 | section_idx、section_path；没有 section_id | parent.structure_id 与 structures.id；没有已发布 idx 目录 | 适配器冻结目录并投影兼容 idx；新增 section_id，idx 仅在固定版本目录内有效 |
| 按块读取 | kb_read 仅接受 planid/section_idx | object(chunk_id) 已按 SQLite 主键直接取回完整块 | 工具与 Protocol 增加 chunk_id；校验 planid 和可选章节归属；原父块及补充上下文父块分开 |
| 续读 | 章节开头最多6000字，没有 offset | 41个原生块本身超过6000字，最长91631；原文完整保留 | read/工具增加 offset、next_offset、read_scope；完整原文读取与每次模型输入预算分开 |
| Passage.chunks | 只列整段落在返回页内的完整片段 | 当前没有对应 Passage 投影 | 新 ChunkSpan 保存完整块范围、可见交集范围及 complete；分页部分块不能被登记成已读完整块 |
| 证据登记 | 同 chunk_id 后登记覆盖之前范围；目前主要校验 ID | 原文/关系可回取，但没有已接入的证据登记适配 | context.py 合并 observed_ranges；同 ID 的版本/完整范围冲突拒绝，不因多个正常分页范围不同而拒绝 |
| 引句真实性 | Claim.quotes 没有逐字核对 | 快照哈希与原文范围齐全 | output.py 增加可见范围及原句一致性校验；位置通过不等于语义受到支持 |
| 错误状态 | not_found/no_text/timeout/backend_error 等 | 内部多用 ValueError/SQL异常/None，没有 KBNotFound/KBNoText 适配 | 适配器区分空文档、未知ID、归属错误、索引不可用；保持 ToolResult 状态；未知chunk不伪装空文档 |
| 图片/OCR | 现有 Hit/Passage 坐标均按原生文本设计 | 已有 OCR文本、原图与局部图；转录坐标和像素/归一化框独立 | 先显式过滤 text_chunk；随后增加带 source_type 的媒体证据类型，不能给OCR填写MD正文坐标 |
| 原文入口 | 尚无真实原文服务 | 本地冻结快照，相对路径可定位 | 先保存结构化 locator；前端/HTTP开放时再增加受控路由，不能把文件路径称为公开URL |

旧 Hit/Passage 的 Pydantic 配置会忽略额外字段。本轮脚本实际验证旧类型会丢弃 chunk_char_start/end、section_id、版本定位、next_offset 等新增字段；必须联动修改类型和证据登记，而非仅给底层字典增加键。

## 二、与原检索设计方案的冲突及修订

| 原设计或缺口 | 核查结论 | 本轮对方案的处理 |
|---|---|---|
| 主存储写 Qdrant＋PostgreSQL；全文写“未实施” | 用户已选本地降级版并完成建库，但 Agent 真实接入未完成 | 检索方案改用 SQLite＋Qdrant Local＋BM25S 为当前路径；概要/存储设计增加阶段状态与本地实现入口 |
| 以 evidence_id 绑定批次和实际引用范围；Agent 却用 chunk_id | 二者不是同一种身份，不能强迫重新编号现有切块 | chunk_id 作为稳定来源身份；run 内证据记录另存可见范围/版本，若另建 evidence_id 作为记录ID，不替换 chunk_id |
| “原句不能截断”与 Agent 300字/6000字预算 | 预览可能合法截断，但不得将预览当作完整条文证据 | 预览明确 truncated；完整原文不截断保存；引用仅使用已读范围及完整条件，显式按需续读 |
| 原方案未规定常驻加载与并发 | 现有逐次开库会重复装载，还存在 SQLite 线程边界 | 新增启动/关闭生命周期、单个库工作线程共享及发布固定要求，作为待实施验收项 |
| 章节编号/坐标原点未写到可互操作程度 | body 解释、章节idx和真源ID可能各有一套 | 固定完整MD码点坐标；沿用RAG ID，idx目录按版本冻结，不编造标题 |
| 标题、条件、表头增强与“原文片段”可能混淆 | embedding 输入不是连续原文；必要关联可能在别处 | 主content保持单一原文范围，contexts/relations独立提供原文坐标与角色 |
| 依赖未解决的块是否允许被检索 | 后续用户已明确要求完整覆盖，质量问题只提示；原库保留 pending/reasons | 保留召回资格，返回质量/上下文不足标签；不能因入库就当作完整证据，也不恢复“必须全量人工签字” |
| 原方案同一路多表示先合并，再RRF | 实际 query 目前按 representation 融合，最后按source去重 | 修订方案保留先按source取最好名次的目标，明确当前尚未实现；适配时不应将多个表示当不同引用来源 |
| 父块回取借用 LangChain 的表述可能被当作现成实现 | 本地实际为 source/parent 对象回取，没有 LangChain ParentDocumentRetriever | 方案改为沿用现有父子关系与直接回取，不额外创建第二套父子块或章节ID |
| “verified”可能被理解为政策回答正确 | Agent 当前仅能确认引用ID登记，quotes仍未经逐字验证 | 明确身份/范围/原句校验与结论支持区分；本轮不声称生产引用或回答语义已全部验证 |

## 三、本轮边界与后续验收

本轮已完成：真实产物核查、原文范围/ID重算、真实 BM25 命中、Hit/Passage 投影、两页重建验证、设计文档与本目录 README。Agent `kb_contract.md` 保持现有 V0.1 实施含义，未直接改成“V0.2 已实现”。

下一轮生产实现至少验证：启动只加载一次；多个请求共享同一实例且证据不串 run；SQLite/Qdrant 无跨线程或路径锁错误；两路按同一版本/过滤集合召回；同一块多表示归一；按chunk/章节读取与6000字后续读；错误planid拒绝；CRLF/非BMP字符/重复句坐标；已见范围登记与引句校验；重建索引ID不变；旧版本引用可回看。当前核查结果只覆盖其中已明确标出的数据检查项。
