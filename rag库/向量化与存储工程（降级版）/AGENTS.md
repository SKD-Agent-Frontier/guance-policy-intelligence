# 降级版本地向量化与存储维护约定

- 本目录按用户明确要求采用 SQLite + Qdrant Local + BM25S。原版 PostgreSQL/Qdrant Server 工程和上游切块只读，不修改或删除；不恢复已删除的开源切块版。
- 保留独立 MetadataStore、VectorStore、LexicalStore 接口。业务处理通过 storage.open_stores 装配；本地数据不能被描述为服务端数据库。
- 文本/图片向量化、OCR、输入计数、缓存、父块和引用定位继续复用原工程规则，不重新切块，不伪造缺失图片或模型结果。
- 完整覆盖模式继续保留全部现有子块，质量问题只提示；硬上限前进行完整输入分片，原文与父块不得截断。
- SQLite 是发布权威。来源、任务、Qdrant 成员、BM25 成员全量校验后才切换指针；不声称三存储存在统一事务。
- 硬链接只用于不可变快照/缓存；数据库必须独立存放，禁止硬链接可写数据库或原地覆盖共享缓存。
- 使用项目锁及 Qdrant 单路径锁，不能删除锁绕开并发限制。备份前关闭所有本地库；恢复到新目录后复核。
- 凭证只放被忽略的本地文件。正式数据、环境、缓存和数据库不进 Git。报告区分迁移复用与新模型调用，以及测试夹具和真实数据验证。
- 代码关键规则用中文解释；每次目录、接口、输出或实际运行状态变化同步更新 README。相关检查后只提交本任务文件，不推送。
