# 一、“十三五”期间卫生和计划生育事业发展情况

“十三五”期间，宏伟区卫健局卫生和计划生育工作在区委、区政府的正确领导下，在上级主管部门的精心指导和社会各方面的大力支持下，在卫健系统全体职工的共同努力下，以党的十八大、十九大、十九届三中、四中全会精神为指导，按照提高人民健康水平，保基本、强基层、建机制要求，重点推进医疗服务，公共卫生体制综合改革，建立重大疾病保障和救助机制，完善突发公共卫生事件应急和重大疾病防控机制。巩固基本药物制度。健全农村三级医疗卫生服务网络和城市社区卫生服务体系，深化公立医院改革，鼓励社会办医。扶持中医药事业发展，提高医疗卫生队伍服务能力，加强医德医风建设，全面实施“十三五”卫生和计划生育工作发展规划，取得了卓有成效的成果，实现了预期的发展目标。

（一）充分发挥疾控作用，努力做好全区疾病控制、卫生监督工作。

我区专业公共卫生机构作用明显。2019年初，机关事业单位机构改革，组建宏伟区卫生健康服务中心，承担全区疾病控制、卫生监督、妇幼保健、计划生育服务等职能。充分发挥对基层医疗机构的业务指导和监督职责，尤其对非法行医、院感控制、传染病防控等方面发挥着重要的作用。“十三五”期间，全区未发生重特大医疗事故和院感事件。在新冠肺炎疫情期间，区卫生健康服务中心承担着重点管控人员医学观察指导、流行病学调查、消毒消杀、核酸采样等工作。在全区“重强抓”工作中，圆满完成妇女“两癌”筛查和新生儿免费疾病筛查等妇幼保健工作。宏伟区妇幼保健计划生育服务中心被评为2013-2017年度辽阳市“三八红旗集体”。宏伟区卫健中心2020年被评为辽阳市“五一奖章“先进集体”。

（二）积极推进基层卫生医疗机构建设，完善基层医疗卫生服务体系。

两镇卫生院都先后纳入到了由市中心医院、市中医院、市三院牵头的综合性医院医联体、中医医联体、妇幼医联体中。 曙光镇卫生院改扩建已完成，并通过省级验收，改建后的卫生院委托辽阳辽化医院进行运营管理，促进优质医疗资源下沉，提升基层医疗服务能力，利用辽化医院的医疗资源来提高基层专业技术、人员匮乏、能力不强等问题，通过对口扶持、业务指导、远程会诊、信息互通等方式，提升农村医疗技术整体水平；龙鼎山社区卫生服务中心已建立远程会诊平台，以云医院为依托，开展网上协同门诊、双向转诊、远程医疗等协同诊疗服务。

（三）扎实推进基本公共服务，巩固和完善十四项基本公共服务项目成果。

全面实施基本公共卫生服务项目。2018年基本公共卫生由原来的12项增加到14项，每年根据国家任务要求，与财政局联合下发《基本公共卫生服务项目实施方案》，截止到目前全区共建立居民健康档案134924人，建档率达95%，建立电子档案123762份，电子建档率87.14%，此项工作基本已覆盖全区。

（四）加强以全科医生为重点的基层医疗卫生队伍建设。

通过全科医生转岗培训，提高我区全科医生队伍建设。截至目前我区已注册全科医师48人，其中西医全科医生注册42人，中医全科医生注册6人。

（五）大力发展中医药事业，卓有成效地推进中医药创建工作。

按照辽宁省人民政府《关于印发促进中医药发展实施方案(2016—2020年)的通知》要求，以中医药服务能力提升工程为目标，宏伟区龙鼎山社区卫生服务中心“中医馆”建设通过了市级考核验收，2019年宏伟区美年大社区卫生服务中心和兰家镇卫生院中医馆创建工作已完成，分别建立了“治未病”科室，通过科室建立，未病先防，有效措施干预，从而全面发挥中医药在维护广大人民群众身体健康的作用。2019年底，辖区内可以提供6类中医药技术的社区卫生服务中心和乡镇卫生院达到100%，提供4类中医药技术的社区卫生服务站达到100%，村卫生室达到68%，已完成了十三五规划指标。

（六）积极推进医养老结合，努力打造以健康养老为目标新模式。

2017年，我局根据上级相关文件精神，结合我区实际情况，形成《宏伟区推进医疗卫生与养老服务结合发展实施方案》。辖区内二级医院均开设老年人就医绿色通道，并在政府网站上进行公示。根据国家、省、市关于推进医疗卫生与养老服务结合发展的要求，我区12家养老机构与8家医疗机构全部进行了签约，签约率达到100%。

2019年，国家放开医养结合机构审批权限改为备案制度，真正实现了医中有养，养中有医，由健康养老至临终关怀全过程服务，配备了较强的医疗和护理队伍，使我区的医养结合工作日益走向专业化、规范化发展道路。

（七）全面实施两孩政策，落实各项计划生育家庭奖励和扶助政策。

全面贯彻落实《中华人民共和国人口与计划生育法》和《辽宁省人口与计划生育条例》实施一对夫妇可生育两个孩子政策。改革生育服务管理制度，实行生育登记服务制度。

进一步优化办事流程，简化办理手续，推行一站式服务、限时办结、个人承诺和委托代办等多种便民措施。充分利用舆论引导，多方式、多渠道开展全面两孩宣传并做好政策解读，主动正确回应社会关切。农村独生子女0-18周岁父母奖励费（直通车）、城镇双无业0-18周岁独生子女父母奖励费、农村部分计划生育家庭奖励费，计划生育特殊家庭扶助费等各项计划生育家庭奖励和扶助政策均全面落实到位。

# 二、“十三五”期间存在的主要问题

（一）公共专业技术人员配备不足，基层服务力量较弱。

基层社区卫生服务机构缺乏中、高级卫生技术人才，个别村卫生室村医仅持乡村医生证，年龄偏大，服务水平和诊疗能力较低，无法满足信息化、规范化的服务要求。

（二）群众健康和卫生意识不强，导致活动参与度不高。

辖区内群众接受服务的主动性、依从性不强，导致家庭医生上门服务入户困难，尤其部分严重精神障碍患者拒绝联系，导致严重精神障碍患者的随访工作、面访率和规范服药率存在较大难度。

（三）核酸检测能力不足，无法满足疫情防控需求。

辖区内缺少独立设置的医学检验实验室，检测能力相对薄弱，导致疫情防控检测压力较大。

（四）人口生育率普遍走低，社会老龄化日趋严重。

我区人口从2016年全面两孩政策放开后，出生人口仍逐年下降。人们生育观念的普遍转变，生育及养育成本的提高使生育率普遍走低，人口老龄化日趋严重。

# 三、“十四五”期间（2021—2025年）卫生和健康事业发展思路及发展规划目标

（一）总体思路

高举习近平新时代中国特色社会主义思想伟大旗帜，深入贯彻落实党的十九大和十九届二中、三中、四中全会精神，以增进广大人民健康福祉为根本宗旨，全面总结“十三五”时期卫生改革与发展取得的成就和经验，认真分析当前卫生健康领域改革与发展面临的形势和要求，把握公益公平，优化资源整合，强化改革创新，突出能力建设，科学谋划“十四五”时期卫生健康领域的改革与发展的重点任务，统筹推进医疗保健、公共卫生、健康服务、人才培养、综合监督、智慧医疗、健康大数据等综合改革，构建起与人民群众健康需求相适应的医疗卫生服务体系，不断提高城乡居民健康素质，促进卫生健康事业全面协调可持续发展。

（二）发展目标

1、到“十四五”期末,改善我区公共卫生服务体系建设，完成宏伟区远郊重大疫情防控救治基地建设项目工作。

2、到“十四五”期末，14项基本公共卫生服务项目服务能力明显增强，实现人人享有基本公共卫生服务目标。

3、到“十四五”期末，全面实施健康中国行动计划，成功创建健康促进县（区）。

4、到“十四五”期末，建立健全卫生综合监督行政执法队伍，提高监督管理执法能力。

5、到“十四五”期末，深入开展职业病危害普查和防控，提升医疗卫生机构职业病防治能力。

6、到“十四五”期末，进一步完善妇幼保健体系，妇幼保健水平全面提高。

7、到“十四五”期末，完善疾病预防控制体系，夯实常规免疫，提升预防接种管理质量。

8、到“十四五”期末，运用现代数字技术，打造智能化疫情防控救治体系。

9、到“十四五”期末，坚持人口生育政策，增进家庭和谐幸福、促进人口长期均衡发展。

10、到“十四五”期末，加强医养结合服务能力，形成政府引导、社会参与、市场驱动的健康养老发展格局。

11、到“十四五”期末，辖区内中医药能力建设全面加强，不断提升基层医疗机构中医药文化水平。

# 四、“十四五”期间卫生和健康事业发展规划的主要任务和措施

（一）进一步提高应对重大公共卫生事件能力。改善我区公共卫生防疫和基本医疗服务的需要，完善国家健康政策，强化政府责任和投入，建设覆盖城乡居民的公共卫生服务体系、医疗服务体系、医疗保障体系、药品供应保障体系，为广大群众提供安全、有效、方便、廉价的医疗卫生服务。

（二）有效促进公共卫生服务均等化，保障人人享有基本公共卫生服务。大力加强基层医疗机构服务规范的培训，提高全区基本公共卫生服务覆盖面，提升全区基本公共卫生服务质量，使全区居民充分享受国家惠民政策，促进健康管理水平与能力不断提高，居民健康素质得到提升。完成国家每年基本公共卫生服务的任务要求。

（三）全面实施健康中国行动，进一步建立健全工作推进机制，抓好监测评价和考核工作。

（四）全面加强疾病预防控制和卫生监督能力建设。做好医疗卫生机构的监管，严格规范医疗行为、行业作风，严肃查处损害群众利益行为。加强城乡居民饮用水终端监管，进一步完善公共场所量化管理工作。健全完善卫生监督执法体系，推动执法重心下移。完善常态化监管机制，加强事中事后监管，实行“双随机”抽查机制，加强全行业监管。对围绕社会高度关注、涉及群众切身利益的卫生突出问题，重点监督检查，严厉打击违法行为。推进信息披露和公开，提高监督执法效率。

（五）加强公共卫生和重大疾病防治，提高医用辐射防护监测与危害控制水平。做好尘肺病等重点职业病监测和职业健康风险评估。深入推进职业人群健康教育，推动用人单位落实职业病防治主体责任，开展用人单位职业健康促进试点。不断提高职业健康检查和职业病诊断、鉴定、救治能力。

（六）全力保障母婴安全，做好艾滋病、梅毒、乙肝筛查管理，降低剖宫产率，提高母乳喂养率。做好免费孕前优生和婚前医学检查工作，降低出生缺陷。做好新生儿实施免费疾病筛查工作, 进一步降低我区5岁以下儿童死亡率和残疾儿童发生率，提高出生人口素质。做好儿童健康体检，指导基层做好0-6岁儿童眼保健和视力筛查工作，促进儿童全面健康发展。加大妇幼宣传力度，提升妇幼公共卫生项目质量，全力推进妇幼健康工作高质量发展。

（七）健全疾控管理机构，通过人才引进的方式，配齐配强疾控专业人员。推动实验室检测能力建设，提升对传染病、地方病、寄生虫病、慢性非传染病、精神卫生等疾病有效预防与控制及突发公共卫生事件应急处理能力。加强免疫规划管理，做好补充免疫和查漏补种，推进接种门诊规范化建设，加强疫苗可预防传染病监测。探索建立预防接种异常反应补偿保险机制。加强疫苗冷链管理，推进疫苗全程追溯体系建设。

（八）应急物资保障储备和调拨体系进一步健全。改造建设不低于300平的应急物资储备库，达到防护用品、消毒用品、消毒器械及其他应急用品等四大类进行分类储备，分区放置、合理摆放、整齐划一，确保物资使用的方便和安全管理。做到关键时刻调得出、用得上。巩固省卫生应急示范区成果，增强公众卫生应急自救互救能力，全面提高全区应急处置和反应能力水平。

（九）实施全面两孩政策，改革完善生育服务管理。不断健全完善利益导向机制。落实计划生育各项优惠、奖励、扶助和社会保障的政策和规定。保持宏伟区农村独生子女0-18周岁父母奖励费（直通车）、城镇双无业0-18周岁独生子女父母奖励费、农村部分计划生育家庭奖励费，计划生育特殊家庭扶助费兑现率均达到100%。

（十）推动医养融合，全面促进健康养老。支持有条件的养老机构开办或内设医疗机构，为老年人提供优质便捷的诊疗康复护理服务；鼓励基层医疗卫生机构将护理、康复、健康管理等服务延伸至家庭，让老年人真正获得幸福感。

(十一)加强中医药服务能力，促进中医药传承发展。不断提升乡镇卫生院和社区卫生服务中心中医馆、国医堂等中医综合服务区建设，加强中医药设备配置和中医药人员配备。提高中医药防病治病能力，大力发展中医非药物疗法，充分发挥其在常见病、多发病和慢性病防治中的独特作用。大力发展中医养生保健服务，发展中医药文化产业。推动中医药与文化产业融合发展，探索将中医药文化纳入文化产业发展规划，不断提升中医药与文化产业融合发展水平。
