# 问答质量首批优化与真实验收

## 结论与交付边界

此批修复已复现的任务解析、检索主题和显式文献范围问题，保留原有引文、数字和版本核验。复杂比较、跨轮指代和完成度判断仍有缺口，PR 保持草稿，不能据此发布“问答质量已全面稳定”的结论。

原诊断基于旧 Web 分支 `de41c49`。实施时发现 `main@0e6a487` 已包含大量证据和多轮修复，因此本次从最新 main 建分支，并重新运行 12 题真实基线。旧报告中的全部问题不能直接视为最新 main 的现状。

## 已实施

1. 分离明确题名、`planid` 与任务正文；接受 `planid=...`；报告题名、以及“报告要求……”这样的引用措辞不再自行触发分析报告要求。数值事实的 subject 若只是明确来源题名，不要求引句再次包含题名，来源仍单独核验。
2. 补充对象切换动词的地区规范化，并保留“从江县”等真实短地名。
3. 对通用维度查询保留主题及人群；“大学毕业生/高校毕业生”“找工作/就业”等只作检索扩展，不作政策适用对象相同的证据。
4. 开放候选先按主题词相关性分组，再做来源多样性排序，避免第二条相关证据被无关文件挤掉。不改变候选身份或索引。**这是词面排序修正，不是新接入的语义 reranker。**
5. 逐字补句增加主题约束；生成与语义审核提示明确保留人群、时间、数量边界，区分目标与成效，禁止从少量材料推广到各地、从未检索到推断政策不存在。
6. 国家与江苏被分别明确指定为比较对象时，允许所选国家文献进入取证；“仅使用江苏省文献”等排他范围仍阻止越界。
7. 增加真实服务验收脚本、12 题失败回归集和 30 题扩展挑战集，分别保存失败记录、原始调用和源码指纹，避免混用代码版本或挑选成功重试。
8. 扩展题发现问题后，补充“区别”不是行政区的解析规则；“这项/这条”可延续已核验来源身份，纯数字/要求指代带回上一问题的主题重新取证；“原文依据”按引用要求处理，不伪装成正文检索的章节名。

- 自动化：最终代码 Agent + Web backend **1,469 passed / 6 skipped**，Ruff 与 diff 检查通过。先观察到原 7 条回归失败；真实复测又发现报告引用措辞及数值题来源 subject 问题，新增 2 条失败回归；扩展及追问复测再新增 4 条失败回归后修复。测试总数还包含已有用例及参数化场景。
- 真实数据：已发布冻结版本的 **506 篇**目录，`generation_id=local_generation_e125cd0f3a4faf24860081796440a6e73f26196edb6bb838dd93c7a92ec1078f`。使用独立元数据/BM25 快照及独立会话，原始材料只读；未重建或修改生产索引。
- 真实模型：本地已配置的 `qwen3.8-27b`，BM25，原配置 temperature 未指定，输出预算 2,000 token，总预算 180 秒；未替换框架、模型或生产配置。原始认证信息及调用记录不入库。
- 基线为串行 12 题各一次；首批版本采用 12 题各三次、进程内并发 3 的重复探索。两者不是严格控制并发的延迟 A/B，不能据此宣称提速。
- 修复中间版本的 14 份结果单独保留，不混进最终版本统计。最初服务读取中断的两次记录独立归为环境故障，没有删掉后当作成功样本。
- 使用真实 backend ASGI 入口及真实模型/RAG；这不包含浏览器网络、操作系统托管及长时间进程稳定性。

`completed` 不是准确率，`verified` 也不代表切题、完整或推理正确。30 道题没有专家金标，部分改写模式已参与开发测试，所以不作为独立盲测或全库 Recall@20 基准。

## 扩展题与追加修复复测

30 道扩展题各运行一次，进程内并发 3，全部主请求结束且 HTTP 200；其中 H11 暴露了“区别”被误作地名，H22 暴露了数字指代取证失败。原始 30 题观察保留在 [扩展诊断记录](extended-observations.json)，不把发现问题后使用的题继续称为保留盲测。

在最终生产修复 `9538944` 上重新运行 7 次主请求（M1 三次及 H11/H22/H23/H30 各一次，另含 5 次种子轮）：

- M1 三次均识别 continued、限定来源 12915、用“企业降成本”回读真实原文；两次明确区分 2019 年“900 亿元以上”目标与 2018 年“952.3 亿元”历史效果，一次只列两条原句、未解释其关系，因此没有达到三次完整交付。
- H22 能回读 12915 的目标原句，仍被模型生成的题名 subject 与审核撤回判为部分完成。
- H11 不再被伪造地名拦截，实际进入检索；仍无最终有效事实，不能视作比较修好。
- H30 的“仅江苏省文献”与国家文献选择冲突仍被拦截，未静默放宽范围。
- H23 的无 planid 文献切换仍未取得目标材料，保持失败记录。

仅调整了“区别”解析边界，原 12 题的地区解析前后全部相同；追加修复另跑全套 1,469 项测试与上述真实受影响用例，没有重复挑选原 36 次结果。

最后对 5 道指定文献题做进程内五并发探索，5 次均 HTTP 200、生命周期 completed，耗时 9.14–53.00 秒，内部引用状态仍有不足；这只证明此批请求没有传输/生命周期错误，不证明五人真实浏览器质量、内存不增长或进程长稳。详见 [追加复测及负载记录](followup-and-load-observations.json)。

独立读取原始元数据中的来源对象，对基线 12 次、首批重复 36 次、扩展 30 次、最终受影响 7 次和五并发 5 次共 **90 次主请求、319 条引句**复核：planid/source_hash 对应关系与忽略空白的原句匹配未发现问题；原始元数据与 BM25 的 8 个清单文件 SHA256 均未变化。此核对不能证明事实切题、政策含义正确或答案完整，尤其不能把此前 M1 的真实无关引句计为正确回答。

## 已确认的收益与剩余问题

最新 main 的真实基线中，F1 没有取得降成本答案，M2 切换后也没有取得该事实。最终版本的串行 smoke 两题均回答 **“900 亿元以上”**，引用正确报告，内部交付状态为 complete；原文位于“2019 年工作重点”，是报告提出的要求，不能写成已实现效果。

国家/江苏比较已不再在入口因省级范围而直接被拦截，但不等于比较已完成。真实复测发现：正文查询仍可能混入未加书名号的短题名；阅读可能只覆盖一方；审核后可能保留很少内容。就业改写也仍有无证据返回，不承诺已消除模型与编排的不稳定性。

首批 M1 的“这项要求”没有被上下文解析识别为指代，曾从别的文献读到真实但不相关的事实；一次记录甚至出现 evidence_status=verified、答案却是不能判断的组合。追加修复已纠正指代与取证来源；三次最终回答仍有一次未完成性质判断，因此后续还要解决意图、分析交付和最终状态的一致性。

数值事实的“题名不是 subject”已修复；综合题仍可由模型计划产生文献题名/地区充当主题的要求，导致正确事实被判 subject_uncovered。语义审核还会因引句不完整撤回结论，也可能丢失已生成的条件说明。这些问题不能通过放松核验来消除。

## 后续批次的准入条件

1. 针对上述真实失败补充端到端回归：明确标题/行政范围与正文主题分离、跨轮指代只继承已核验对象、明确切换不继承旧范围；相同要求在检索、生成、审核和最终状态中使用一致身份。
2. 在同一候选集上人工标注相关性后，比较词面排序与可部署语义重排序；正确证据未进入候选集时先查召回。此批未将未经对照的语义重排序或混合检索默认上线。
3. 比较题逐对象、逐共同维度组织证据；补句和邻接阅读受预算约束；数值、适用人群及“以上”等条件需原文复核。不得以事实数或内部覆盖分数冒充质量提升。
4. 另建专家核对的独立保留集，验证低随机性参数的服务支持及实际收益；本次没有为通过验收调低 temperature 或选择最佳重试。
5. 分别验证 1/3/5 并发、网络/API 边界和进程托管长稳。进程内并发探索不能证明五人浏览器验收或生产长稳。

## PR #41 后续加强：多来源取证及完成判定（2026-11-05）

本节是本 PR 后续新增修复的记录；与上面的 90 次真实模型请求属于**不同代码快照**，不得把原先的真实结果充当本批最新代码的通过率。

- **取证预算**：显式选择两份文献时，在上限四次搜索内预留按每个 planid 单独检索的机会；多文献比较不再因第一份文献的完整章节回读而直接跳过另一份。所有候选仍须经过各自原文 `kb_read`，不增加未核验的证据。
- **任务交付**：两份明确选择的文献即便没有在自然语言问题中重新写出篇名，仍触发多文献覆盖要求和生成约束。跨文献分析仅在同一可见的审核分析块确实关联到至少两个**存活且经过逐字核验的事实来源**时，才可能通过完整性检查。
- **多轮切换**：明确给出新篇名或新 `planid` 时，即使地区相同，也不再默默继承上一轮的已核验文献身份；新文献仍需重新检索与回读。
- **验收脚本安全边界**：不允许真实服务验收数据写入源码仓库目录，保留已有源码版本和题集指纹检查。
- **验证边界**：新增的是确定性回归测试和 CI；尚未对修改后的完整分支重新运行真实 Qwen + 506 篇的独立对照，更未完成原有 572 条四轮场景全套验收。因此本 PR 继续保持 Draft，**不能声称跨文献比较或自主研究能力已经稳定**。
