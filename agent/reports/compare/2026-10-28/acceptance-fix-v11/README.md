## 本轮修正

- 修复“在建筑”误识别为在建，以及“不能认定已完成”被当成实际进度断言的误报。
- 原有分析复核接收具体撤回或缺项原因。格式修正与空选择定向复核共用一次纠正预算，正常4次、最多5次，仍受底座预算和超时约束。
- 每格仅保留一个完整语义单元，培养期句保留与之绑定的对象；纯部门任务分工不充当受益对象。
- 保留服务主体、重大项目门槛、个人条件及岗位口径；禁止将用好基金改为新设基金、部门考核改为个人资格、举荐制度改为人人必经路径。
- 限制判断不合并不同单元格；适用条件直接逐条核对完整原文。优势遗漏或服务主体概括无效时，仅在存在明确支持证据时保守列出原文支持特征。
- 有效分析均显式限定于本次所列条款；无效候选撤回原因单独记录，不把被拒绝文字留在交付结构中。
